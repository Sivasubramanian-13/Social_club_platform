# ✨ Animated Social Club Platform

A modern and interactive social networking platform where users can connect, share posts, and engage with a community through a smooth, animated user interface.

## 🚀 Features
- 🔐 User Registration & Login
- 👤 User Profiles
- 💬 Social Interactions
- 📝 Share Posts & Updates
- 🎨 Smooth CSS Animations & Transitions
- 📱 Responsive Design

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MySQL

## ⚙️ Installation

```bash
git clone <your-repository-url>
cd animated-social-club
npm install
node server.js
```

Open `http://localhost:3000` in your browser.
